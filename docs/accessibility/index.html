Apple accessibility categories

Seven ways Loom adapts.

These capabilities are built into the current development version. Final Accessibility Nutrition Labels are reported release by release after the exact submitted build completes Loom's accessibility test matrix.

◉ Engineered support

VoiceOver

Explore Loom with spoken descriptions, braille, keyboard input, and familiar VoiceOver gestures.

  • Controls expose useful names, values, hints, and selection states
  • Charts and progress visuals provide spoken values and adjustable actions
  • Gesture-driven cards include named alternatives, while decorative visuals stay out of the focus order
⌁ Engineered support

Voice Control

Use spoken commands to activate named controls, enter text, navigate lists, and move through core planning flows.

  • Native buttons, menus, fields, and toggles preserve standard Voice Control behavior
  • Explicit control names work with Show Names and Show Numbers
  • Complex interactions provide direct named actions instead of requiring one precise gesture
Aa Engineered support

Larger Text

Follow the device's Dynamic Type setting through accessibility sizes, including text enlargement to 200% and beyond.

  • Choose Use iPhone Text Size or a Loom-only Accessibility text preset
  • Core layouts stack, expand, or scroll as text grows
  • Line limits relax and primary controls grow to preserve readable content and useful touch targets
◒ Engineered support

Dark Interface

Use a dark color scheme across Loom's screens, menus, cards, and controls to reduce brightness and eye strain.

  • Follow the iPhone or iPad appearance automatically
  • Force Light or Dark inside Loom without changing the whole device
  • Semantic backgrounds, text, borders, and data colors adapt together
△○ Engineered support

Differentiate Without Color Alone

Understand status and meaning through shapes, symbols, labels, and values—not color alone.

  • Charts add visible markers and patterns when differentiation is enabled
  • Selected, completed, and disabled states include text, checkmarks, shapes, or spoken values
  • Follow the system setting or turn the behavior on only inside Loom
◐ Engineered support

Sufficient Contrast

Increase separation between text, symbols, controls, and their backgrounds in both light and dark appearances.

  • Adaptive semantic colors strengthen text and status boundaries
  • Increase Contrast can follow the device or be enabled only in Loom
  • Core Fulfillment surfaces include automated 4.5:1 contrast checks in light and dark modes
Ⅱ Engineered support

Reduced Motion

Reduce or remove movement that can distract, cause discomfort, or make the interface harder to follow.

  • Follow the system Reduce Motion preference or override it inside Loom
  • Looping, rotating, parallax, celebration, and typing motion stop or become static
  • Navigation and status remain available without depending on an animation finishing

Choose what works

Use your device settings—or choose inside Loom.

System assistive technologies remain controlled by iPhone or iPad settings. Loom's display and motion preferences can follow the system automatically or use an app-only override.

  1. Open Loom's Account area.Select Account from Loom's main navigation.
  2. Choose Accessibility.Open the dedicated Accessibility screen under Account.
  3. Select a display or motion preference.Adjust Text Size, Reduce Motion, Reduce Transparency, Increase Contrast, Differentiate Without Color, or Dark Interface.
  4. Follow the device or override Loom.Use the iPhone setting, or choose an option that applies only inside Loom.
Release-by-release evaluation

Accessibility claims require the whole workflow.

Apple's criteria require every common task to work with a reported accessibility feature. Loom therefore treats a feature as an App Store declaration only after automated audits and physical-device testing pass on the exact release build.

Testing covers light and dark appearance, accessibility text sizes, assistive technologies, contrast, non-color cues, reduced motion, reduced transparency, focus order, control names, and touch targets.

Accessibility FAQ

A few useful details.

Does Loom support VoiceOver?
Loom's current development build includes semantic labels, values, hints, named actions, adjustable chart controls, and focus handling designed for VoiceOver across core planning flows. Final App Store accessibility declarations are verified release by release.
Can Loom text be enlarged to 200% or more?
Yes. Loom follows the iPhone or iPad Dynamic Type setting through accessibility sizes and also offers a Loom-only Accessibility text-size preset. Core layouts reflow, expand, or become scrollable as text grows.
Can I use a dark interface without changing the whole iPhone?
Yes. Choose Account → Accessibility → Dark Interface, then select Dark. You can also choose Light or return to Use iPhone Setting.
Why are Captions and Audio Descriptions not listed as supported features?
Loom does not currently include video or audio playback as part of its common tasks, so Captions and Audio Descriptions are not applicable to the app today.
Where can I report an accessibility issue?
Email spencer@loomlife.us with the device, operating system version, Loom screen, accessibility setting, and a short description of what happened.
